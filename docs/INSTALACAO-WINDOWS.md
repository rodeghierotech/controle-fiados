# Uso no computador da loja

O Controle de Fiados é acessado pelo navegador após a publicação na Vercel. Não é necessário instalar Node.js, executar `npm ci` ou criar atalhos no computador da loja.

Use o endereço publicado, entre com a conta de administrador e saia da conta ao terminar. A conexão com a internet é necessária para consultar e registrar dados.
